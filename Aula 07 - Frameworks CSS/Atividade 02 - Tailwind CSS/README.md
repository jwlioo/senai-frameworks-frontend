# Atividade 02 - Tailwind CSS

Interface criada com o **Tailwind CSS Play CDN**, sem etapa de compilação. Abra `index.html` no navegador com internet para carregar o framework.

## Classes utilizadas

| Grupo | Exemplos | Função |
| --- | --- | --- |
| Cores | `bg-slate-950`, `text-white`, `border-cyan-400` | Fundo, texto e bordas |
| Tipografia | `font-sans`, `font-black`, `text-4xl`, `tracking-tight` | Fonte, peso, tamanho e espaçamento |
| Espaçamento | `p-6`, `px-5`, `mt-12`, `gap-6` | Preenchimento, margem e distância |
| Dimensões | `min-h-screen`, `max-w-6xl`, `h-12`, `w-12` | Altura e largura |
| Bordas | `rounded-2xl`, `border`, `shadow-xl` | Forma e profundidade |
| Layout | `flex`, `grid`, `items-center`, `justify-between` | Organização dos elementos |
| Responsividade | `sm:px-8`, `md:grid-cols-3`, `lg:py-16` | Adaptação a telas maiores |
| Interação | `hover:bg-cyan-300`, `transition`, `hover:-translate-y-1` | Estados visuais ao interagir |

O arquivo usa mais de 30 classes diferentes, cobrindo cores, tipografia, espaçamentos, dimensões, bordas, Flexbox, grid e responsividade.
