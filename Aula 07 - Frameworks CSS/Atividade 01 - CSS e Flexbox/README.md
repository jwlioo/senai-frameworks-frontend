# Atividade 01 - CSS externo e Flexbox

Página com 20 cards criada com `index.html` e `style.css` externos, conforme solicitado na Aula 07.

## Conceitos praticados

- **Box model:** todos os cards utilizam conteúdo, `padding`, `border` e `margin` (via `gap` do contêiner);
- **Flexbox:** `display`, `flex-direction`, `flex-wrap`, `justify-content`, `align-items`, `gap`, `flex` e `align-self`;
- **Responsividade:** media query para telas de até 600px;
- **CSS externo:** arquivo vinculado no `<head>` com a tag `<link>`.

Abra o arquivo `index.html` no navegador para visualizar a atividade.
