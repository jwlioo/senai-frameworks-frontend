# Testes manuais

| Cenário | Resultado esperado |
| --- | --- |
| Buscar "props" | Exibir somente o card Props. |
| Favoritar um card | Alterar o botão para "Favorito". |
| Abrir favoritos sem itens | Exibir mensagem de lista vazia. |
| Remover busca | Restaurar os cards que correspondem ao filtro atual. |

O build de produção também é validado com `npm run build`.
