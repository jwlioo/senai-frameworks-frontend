# Histórias de usuário

- Como estudante, quero cadastrar uma tarefa para não esquecer uma entrega.
- Como estudante, quero visualizar minhas tarefas para organizar meu tempo.
- Como estudante, quero marcar uma tarefa como concluída para acompanhar meu progresso.
- Como estudante, quero filtrar tarefas para localizar rapidamente o que ainda está pendente.
