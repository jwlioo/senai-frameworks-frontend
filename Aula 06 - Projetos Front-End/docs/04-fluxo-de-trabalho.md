# Fluxo de trabalho

1. Registrar o item no backlog.
2. Definir prioridade e estimativa.
3. Mover o item para a sprint.
4. Criar uma branch de funcionalidade.
5. Desenvolver, testar e revisar.
6. Registrar um commit descritivo e integrar à `main`.

Esse fluxo permite acompanhar a evolução e reduzir retrabalho.
