# Requisitos iniciais

| ID | Requisito |
| --- | --- |
| RF01 | Permitir cadastrar uma tarefa com título e prazo. |
| RF02 | Listar as tarefas cadastradas. |
| RF03 | Permitir concluir uma tarefa. |
| RF04 | Permitir filtrar tarefas por status. |
| RF05 | Exibir o progresso das tarefas. |

Os requisitos são a origem das histórias e tarefas do backlog.
